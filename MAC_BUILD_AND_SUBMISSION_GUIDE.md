# 🍏 Полное руководство: Сборка на Mac и публикация в App Store
**Приложение «Как я?» (How Am I?) — Версия 1.0.0**

Данное руководство написано специально для сценария: проект переносится с рабочего компьютера на Mac через Google Диск (или флешку) и собирается локально в Xcode для отправки в App Store / TestFlight.

---

## 📌 ЧАСТЬ 1. Подготовка к переносу (на Windows перед отправкой в Google Диск)

### ⚠️ Главное правило переноса:
**НЕ копируйте папки `node_modules` и `.expo`!**

Почему:
1. Они весят сотни мегабайт и содержат более 40 000 мелких файлов — Google Диск будет синхронизировать их часами.
2. Внутри `node_modules` находятся скомпилированные под Windows бинарники, которые на Mac вызовут ошибки.

### Что делать:
1. Удалите папку `node_modules` в `how-we-feel/` перед заливкой на Google Диск (или запакуйте всю папку проекта в `.zip`, исключив `node_modules` и `.expo`).
2. Загрузите чистую папку проекта на Google Диск.
3. Скачайте её на вашем Mac.

---

## 📌 ЧАСТЬ 2. Подготовка окружения на Mac (разово)

Если на Mac ещё не собирались iOS-приложения, выполните следующие шаги:

1. **Установите Xcode:**
   - Откройте **Mac App Store**, найдите **Xcode** и установите его (бесплатно).
   - Запустите Xcode хотя бы один раз, чтобы он доустановил компоненты (macOS components / iOS SDK).
2. **Установите Command Line Tools:**
   - Откройте приложение **Терминал** на Mac и выполните:
     ```bash
     xcode-select --install
     ```
     (в появившемся окне нажмите «Установить»).
3. **Убедитесь, что установлен Node.js:**
   - В Терминале проверьте:
     ```bash
     node -v
     ```
   - Если Node.js не установлен — скачайте LTS-версию с официального сайта [nodejs.org](https://nodejs.org) или выполните `brew install node`.
4. **Авторизуйте Apple ID в Xcode:**
   - Откройте **Xcode** -> в строке меню нажмите **Xcode** -> **Settings...** (или `Cmd + ,`).
   - Перейдите во вкладку **Accounts**.
   - Нажмите снизу кнопку `+` -> выберите **Apple ID** -> войдите под своей учётной записью разработчика Apple Developer.

## 📌 ЧАСТЬ 3. Сборка проекта на Mac (Автоматически или Вручную)

Перейдите в терминале в папку скачанного проекта:
```bash
cd ~/Downloads/how-we-feel   # или ваш путь к папке проекта
```

### Вариант А: В один клик через готовый скрипт (Рекомендуется)
Мы уже создали готовый скрипт сборки прямо в проекте:
```bash
chmod +x build-ios.sh
./build-ios.sh
```
Скрипт сам:
- Установит зависимости (`npm install`).
- Сгенерирует нативную папку `ios/` со всеми CocoaPods (`npx expo prebuild`).
- Автоматически откроет готовый рабочий проект `howami.xcworkspace` в Xcode.

---

### Вариант Б: Пошагово вручную (если хотите выполнить команды сами)
1. Установите зависимости:
   ```bash
   npm install
   ```
2. Сгенерируйте нативный iOS-проект:
   ```bash
   npx expo prebuild --platform ios --clean
   ```
3. Откройте Xcode Workspace:
   ```bash
   open ios/howami.xcworkspace
   ```
   *(⚠️ Важно: открывать именно файл `.xcworkspace`, а не `.xcodeproj`)*

## 📌 ЧАСТЬ 4. Подпись и сборка архива в Xcode

Когда проект откроется в Xcode:

### 1. Настройка Signing (Цифровая подпись Apple):
1. В левой колонке (Project Navigator) нажмите на самый верхний синий значок проекта **howami**.
2. В центральной части окна выберите таб **Signing & Capabilities**.
3. Убедитесь, что стоит галочка **Automatically manage signing**.
4. В поле **Team** выберите вашу команду Apple Developer (ваше имя или организацию).
5. Проверьте поле **Bundle Identifier**:
   - По умолчанию стоит `com.howami.app`.
   - *Важно:* если этот идентификатор уже занят кем-то в мире в Apple Developer Portal, замените его на ваш уникальный (например, `com.yourname.howami`). Если меняете, не забудьте указать такой же в `app.json`.

### 2. Подготовка к архивации:
1. В самом верху окна Xcode, рядом с кнопками Play/Stop, нажмите на выбор целевого устройства (где написано, например, *iPhone 16 Pro*).
2. Выберите в выпадающем списке пункт: **Any iOS Device (arm64)**.
   *(Для сборки в магазин нельзя выбирать конкретный симулятор!)*

### 3. Сборка архива (Archive):
1. В верхнем меню macOS нажмите: **Product** -> **Archive**.
2. Xcode начнет компиляцию проекта (займет 1–3 минуты).
3. По завершении автоматически откроется окно **Organizer** со списком архивов.

---

## 📌 ЧАСТЬ 5. Загрузка в App Store Connect

В открывшемся окне **Organizer**:
1. Выберите свежесобранный архив версии `1.0.0 (1)` и нажмите синюю кнопку **Distribute App** в правой панели.
2. Метод распространения: выберите **App Store Connect** -> нажмите **Distribute** (или Next).
3. Пункт назначения: выберите **Upload** -> нажмите **Next**.
4. Настройки дистрибуции: оставьте все галочки по умолчанию (Upload your app's symbols, Manage version and build number) -> нажмите **Next**.
5. На шаге подписи (Signing): выберите **Automatically manage signing** -> нажмите **Next**.
6. Xcode выполнит валидацию и покажет сводку. Нажмите синюю кнопку **Upload**.
7. Дождитесь надписи **App Store Connect distribution succeeded!** 🎉
   *(Билд успешно отправлен в облако Apple).*

## 📌 ЧАСТЬ 6. Оформление и запуск в App Store Connect

После отправки билда:

1. Откройте браузер и перейдите на [appstoreconnect.apple.com](https://appstoreconnect.apple.com).
2. Раздел **My Apps** (Мои приложения):
   - Если приложения ещё нет в списке: нажмите `+` -> **New App**.
   - Платформа: **iOS**.
   - Имя: **Как я? Трекер чувств** (или как вам удобнее).
   - Язык: **Russian** (или English).
   - Bundle ID: выберите ваш зарегистрированный Bundle Identifier.
   - SKU: любое уникальное слово на латинице (например, `howami-ios-01`).
3. **Обработка билда:**
   - Перейдите во вкладку **TestFlight**.
   - Загруженный билд появится со статусом *Processing* (обычно обработка на серверах Apple занимает 10–20 минут).
   - Как только обработка завершится, билд станет доступен.
4. **Привязка билда к версии App Store:**
   - Перейдите во вкладку **App Store** -> версия **1.0.0 Prepare for Submission**.
   - Прокрутите до блока **Build** -> нажмите `+` и выберите загруженный билд `1.0.0 (1)`.
5. **Заполнение карточки (всё готово в папке `app-store-release/`):**
   - Название, подзаголовок, ключевые слова, описание: скопируйте из [`APP_STORE_METADATA.md`](./app-store-release/APP_STORE_METADATA.md).
   - Ссылка на Privacy Policy: скопируйте текст из [`PRIVACY_POLICY.md`](./app-store-release/PRIVACY_POLICY.md) и опубликуйте на любом бесплатном ресурсе (Notion, GitHub Pages, Telegraph, ваш сайт).
   - Анкета сведений о конфиденциальности данных (App Privacy): откройте [`APP_STORE_CONNECT_CONFIG.md`](./app-store-release/APP_STORE_CONNECT_CONFIG.md) — выберите **«No, we do not collect data from this app»**.
   - Анкета возрастного рейтинга: все пункты **None**, итоговый рейтинг **4+** (или 12+).
   - Экспортный контроль: окно с вопросом о шифровании даже не появится, так как мы заранее прописали `ITSAppUsesNonExemptEncryption: false` в `app.json`!
6. **Скриншоты:**
   - Загрузите скриншоты для экрана **6.7" iPhone** (1290 x 2796 px, снимаются прямо в Симуляторе Xcode: `Cmd + S`).
   - *Обратите внимание:* если в `app.json` включен `"supportsTablet": true`, Apple потребует также скриншоты iPad 13". Если пока хотите выпустить приложение только для iPhone, измените в `app.json` `"supportsTablet": false`.
7. **Отправка на проверку:**
   - Нажмите **Add for Review** (Добавить для проверки) -> **Submit to App Review**.
   - Проверка Apple обычно занимает от 12 до 36 часов.

## 💡 Полезные советы:
- **Мгновенный тест на своём iPhone без модерации:** во вкладке **TestFlight** добавьте себя в *Internal Testing*. Вы сразу получите приглашение на почту и сможете установить приложение на свой телефон через официальное приложение TestFlight!
- **Если нужно выпустить обновление (1.0.1):** увеличьте `"buildNumber": "2"` в `app.json` и повторите архив в Xcode.
