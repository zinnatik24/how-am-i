# «Как я?» (How Am I?) — Трекер чувств и настроения

Приложение для осознанности и трекинга эмоционального состояния **«Как я?»** (на базе Yale Mood Meter и метода д-ра Марка Брэккетта).

---

## 📱 Ключевые возможности

1. **4 Квадранта настроения (Mood Meter)**:
   - 🔴 **Высокая энергия, неприятно** (Злость, тревога, стресс, паника...)
   - 🟡 **Высокая энергия, приятно** (Радость, восторг, уверенность, вдохновение...)
   - 🔵 **Низкая энергия, неприятно** (Грусть, истощение, одиночество, скука...)
   - 🟢 **Низкая энергия, приятно** (Спокойствие, благодарность, умиротворение, баланс...)
2. **Точные психологические определения чувств**:
   - Каждая эмоция имеет шкалу интенсивности (1 — лёгкая, 2 — средняя, 3 — сильная) и научное объяснение.
3. **Контекст чекина**:
   - С кем вы находитесь (Один, Друзья, Партнёр, Семья, Коллеги, Незнакомцы).
   - Где вы находитесь (Дом, Работа, В дороге, На улице, Спортзал, Кафе).
   - Чем вы заняты (Работа, Отдых, Общение, Тренировка, Еда, Хобби, Учёба).
4. **Дневник (Journal)**:
   - Лента чекинов по времени и дням с цветовыми маркерами, заметками и тегами.
5. **Тренды и Аналитика**:
   - Распределение по квадрантам в процентах.
   - Топ самых частых чувств.
   - Связь контекста с эмоциональным состоянием.
6. **Мультиязычность (i18n)**:
   - Мгновенное переключение между **Русским** и **English**.
   - Архитектура готова к добавлению 10+ любых языков.
7. **Local-First Конфиденциальность**:
   - Все данные хранятся на устройстве в AsyncStorage, без передачи на сторонние серверы.

## 🚀 Как запустить на iPhone (через Expo Go с Windows)

Вам **не нужен Mac** для разработки и тестирования!

1. Установите на ваш iPhone бесплатное приложение **Expo Go** из App Store.
2. Подключите компьютер и iPhone к одной Wi-Fi сети (или используйте режим туннеля `--tunnel`).
3. В терминале в папке `how-we-feel` выполните:
   ```bash
   npm start
   ```
4. Наведите стандартную камеру iPhone на появившийся в терминале QR-код — откроется приложение в Expo Go!

## 🌍 Как добавить новый язык (например, Испанский или Французский)

1. В [`src/types/index.ts`](./src/types/index.ts) добавьте код языка в `SupportedLanguage`:
   ```ts
   export type SupportedLanguage = 'en' | 'ru' | 'es';
   ```
2. В [`src/i18n/translations.ts`](./src/i18n/translations.ts) добавьте блок перевода строк интерфейса:
   ```ts
   export const TRANSLATIONS = {
     en: { ... },
     ru: { ... },
     es: { ... },
   };
   ```
3. В [`src/data/emotionsData.ts`](./src/data/emotionsData.ts) добавьте названия и определения эмоций для `"es"`.
4. В [`src/screens/SettingsScreen.tsx`](./src/screens/SettingsScreen.tsx) добавьте кнопку выбора языка.

## 📂 Структура проекта

```
how-we-feel/
├── App.tsx                     # Корневой экран с нижней навигацией и провайдерами
├── src/
│   ├── types/                  # TypeScript типы (Quadrant, Emotion, CheckInRecord)
│   ├── data/
│   │   ├── emotionsData.ts     # Таксономия чувств и 4 квадрантов с описаниями
│   │   └── contextTags.ts      # Теги контекста (люди, места, активности)
│   ├── i18n/
│   │   ├── translations.ts     # Словари переводов (EN, RU)
│   │   └── LanguageContext.tsx # Реактивный контекст с автоопределением языка
│   ├── storage/
│   │   └── checkInStorage.ts   # Local-first хранилище (AsyncStorage)
│   ├── components/
│   │   ├── QuadrantCard.tsx    # Карточка квадранта (цвет, энергия, приятность)
│   │   ├── EmotionChip.tsx     # Чип эмоции с точками интенсивности
│   │   ├── EmotionDetailCard.tsx# Карточка с определением чувства
│   │   └── ContextSelector.tsx # Выбор людей, локации и занятий
│   ├── screens/
│   │   ├── HomeScreen.tsx      # Главный экран (Hero, кнопка чекина, Mood Meter)
│   │   ├── CheckInModal.tsx    # Пошаговый флоу чекина (4 шага)
│   │   ├── JournalScreen.tsx   # Дневник и история с удалением записей
│   │   ├── TrendsScreen.tsx    # Аналитика, графики распределения, частые чувства
│   │   └── SettingsScreen.tsx  # Язык, о методике, демо-данные, приватность
│   └── utils/
│       └── haptics.ts          # Тактильный виброотклик (iOS)
```
